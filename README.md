WHAT I LEARNED IN THIS PROJECT:

For Task 2, I built a environmental monitoring system using a DHT22 sensor and a 16x2 LCD display to track ambient condition changes in real time.

Sensor & Display Integration: Wired the DHT22 digital sensor to the Arduino and integrated a 16x2 LCD using standard parallel interface pins (RS, EN, D4-D7).

Software Implementation: Utilized the DHT sensor library to read temperature and humidity readings, handled sensor timing/polling intervals, and formatted the output using the LiquidCrystal library to display real-time metrics clearly on the screen.

Key Takeaway: Learned how to import and work with third-party libraries, handle digital sensor communication protocols, and structure multi-line visual feedback on LCDs.
